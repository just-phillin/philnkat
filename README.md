# Phil & Kat — Wedding Website

A polished, responsive wedding website built for GitHub Pages.

## Update the wedding details

Open `script.js` and edit the `WEDDING` object at the top of the file. Unknown details can remain blank; the site will keep its graceful “coming soon” copy.

Editable fields include:

- Wedding date, display date, and location
- Couple’s story
- Ceremony and reception times, venues, addresses, and map links
- Dress code
- Travel, hotel, and local guide links
- RSVP copy, deadline, and link
- Registry copy and link

The countdown activates automatically when `date` is supplied as an ISO date string.

## Preview locally

Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages

In the repository, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The site will be available at:

`https://just-phillin.github.io/philnkat/`

> A private repository requires a GitHub plan that supports Pages for private repositories. The published Pages site may still be public depending on the account and Pages settings.
